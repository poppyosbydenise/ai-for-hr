# AI for HR

A free, static mini-course and article library on practical AI for People Operations professionals: prompt basics, five mini-agents HR can build, an AI usage policy template, and a guide to building an employee FAQ bot in Slack.

## Run locally
Open `index.html` in a browser. No build step.

## Contents
- `index.html` – landing page
- `course.html` – the course
- `articles/` – standalone guides and templates
